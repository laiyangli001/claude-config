屏幕边缘激光光标行为：使用"贴边吸附滑动"而非"硬锁定上一帧方向"。

**方案:**
- 平滑方向出屏 + 原始方向也出屏 → clamp UV到边缘，计算贴边方向
- 贴边方向与原始方向夹角 < 脱离角(30°) → 吸附，圆环沿边缘随手动滑动
- 超角 → 脱离，射线跟上实际方向
- 原始方向回屏 → 立即脱离

**Why:** 用户测试确认"非常完美"。硬锁定方案被否决，边缘减速方案被否决。
**How to apply:** 这是VR激光指针边缘交互的标准答案，不要再改为锁定或减速方案。
