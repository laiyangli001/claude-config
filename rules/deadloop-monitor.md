# 死循环监控工作流

## 自动流程
1. **ESC 中断** — AutoIt 长按 ESC 5 秒，最多 3 次
2. **确认停止** — 全量扫描 .jsonl 末尾检查 `stop_reason: "end_turn"` 或 `interrupted: true`
3. **确认到停止** → `inject_file` 粘贴注入消息 + 自动提交
4. **未确认到停止** → `paste_file` 只粘贴不发送，等人眼确认
5. 进入冷却 → 恢复监控

## 收到注入消息后的角色
我就是 Claude Code。收到注入消息后：
1. 按 4 点要求生成总结摘要
2. 按"ChatGPT/DeepSeek 代码建议处理"规则，调用浏览器发送问题
3. 收到回答后，如果对方能提供参考代码，要求提供完整代码
4. 按照建议修改 bug

**例外：** 用户明确要求帮忙时，不受自动流程限制，按用户指令执行。
