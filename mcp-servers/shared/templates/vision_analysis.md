## 视觉分析请求

### 任务说明

请对以下图片进行全面分析。

### 点阵归一化坐标系统

为精确定位画面中的元素位置，采用归一化坐标系统：

1. **坐标系基准**：以图片左上角为原点 (0.0, 0.0)，右下角为 (1.0, 1.0)
2. **区域标识**：水平方向 A-J（10 等分），垂直方向 0-9（10 等分），如 A0=左上角，J9=右下角
3. **元素定位**：描述每个元素时附带其归一化坐标范围，格式为 `[x1,y1→x2,y2]`，例如居中按钮为 `[0.35,0.45→0.65,0.55]`
4. **相对关系**：使用"在 XX 的右方/下方/左对齐"等相对描述辅助定位

### 分析模式

#### 模式 A：界面截图分析（用于 UI 调试/Bug 复现）
- 整体布局：结构、分区、边距、对齐
- 元素清单：按钮、输入框、文字标签、图标等，附带归一化坐标
- 异常检测：重叠、偏移、截断、颜色异常、错位
- 交互状态：按钮可用/禁用、输入框聚焦/失焦、加载/空状态/错误状态
- 文字内容：所有可见文本（按钮文字、标签、提示、错误信息）

#### 模式 B：纯视觉描述
- 画面主体和背景
- 颜色、构图、风格
- 文字内容识别
- 细节和上下文

#### 模式 C：图文混合分析（视觉 + 代码 > 搭配代码审查使用）
- 先完整输出界面元素坐标布局
- 标注关键交互元素的状态和行为
- 为开发者提供可操作的定位信息（坐标可直接映射到像素）

### 分析要求

1. 客观描述，不臆测模糊内容
2. 元素描述必须附带归一化坐标（模式 A/C 必须）
3. 按区域顺序描述（从上到下，从左到右）
4. 不确定的内容必须标注"可能/疑似"
