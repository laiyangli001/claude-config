MCP服务 — Claude Code 省token小工具

两个基于 Model Context Protocol (MCP) 的服务器，通过 Playwright 浏览器自动化访问 ChatGPT 和 DeepSeek 网页版。调用时不消耗 API token，支持上传附件。

包含的服务

服务来源说明
ask_chatgpt ChatGPT 网页版 优先使用。自动导航、上传文件、提问、提取回答。
ask_deepseek DeepSeek 网页版 备选。ChatGPT 失败时自动回退到此服务。

前置要求

  • Node.js 18+ — 下载安装

安装步骤

懒人模式：以下全部步骤都可以让 Claude Code 自动完成。直接把压缩包解压到任意目录，然后对 Claude Code 说：
帮我进入 mcp-servers 目录，分别进入 deepseek-mcp 和 chatgpt-mcp 各执行 npm install，然后配置 ~/.claude.json 添加两 mcpServers：chatgpt=node args=[当前目录]/chatgpt-mcp/dist/index.js，deepseek=node args=[当前目录]/deepseek-mcp/dist/index.js
Claude Code 会一步步执行完所有操作，你只需要在首次调用的弹出浏览器里登录一次即可。

1. 解压并安装依赖

# 进入解压后的目录
cd mcp-servers

# 安装 deepseek-mcp
cd deepseek-mcp
npm install
cd ..

# 安装 chatgpt-mcp
cd chatgpt-mcp
npm install
cd ..
必须步骤：安装依赖后还需下载 Chromium 浏览器（约 300MB）。两个服务共用，只需执行一次：
# 下载 Chromium 浏览器
npx playwright install chromium
Chromium 浏览器：由 Playwright 自动管理，下载到 %LOCALAPPDATA%\ms-playwright\

2. 首次登录

两个工具使用不同的浏览器配置文件，需要分别登录一次：

  • 首次调用 ask_deepseek 时，会自动弹出 Chromium 窗口 → 手动登录 DeepSeek
  • 首次调用 ask_chatgpt 时，会自动弹出 Chromium 窗口 → 手动登录 ChatGPT

登录后关闭窗口即可，会话会持久保存。

ChatGPT 用户注意：如果 Cloudflare 验证拦截了 Chromium，可改为 Edge 浏览器 — 编辑 src/index.ts，在 launchPersistentContext 参数中添加 channel: "msedge"。

3. 配置 Claude Code

方式一：让 Claude Code 自动配置（推荐）

直接在 Claude Code 对话框里说：

帮我配置两个 MCP 服务：
- chatgpt-mcp，命令 node，参数 [当前目录]/chatgpt-mcp/dist/index.js
- deepseek-mcp，命令 node，参数 [当前目录]/deepseek-mcp/dist/index.js
写到 ~/.claude.json 里

方式二：手动编辑配置文件

配置文件位置：~/.claude.json（全局）或 .mcp.json（项目级）

{
  "mcpServers": {
    "chatgpt": {
      "command": "node",
      "args": ["/你的路径/mcp-servers/chatgpt-mcp/dist/index.js"]
    },
    "deepseek": {
      "command": "node",
      "args": ["/你的路径/mcp-servers/deepseek-mcp/dist/index.js"]
    }
  }
}
Windows 路径使用正斜杠，如 d:/mcp-servers/deepseek-mcp/dist/index.js

4. 配置自动调用规则（CLAUDE.md）

MCP 服务安装后不会自动被调用，需要在全局 ~/.claude/CLAUDE.md 中添加触发规则。对 Claude Code 说：

帮我在全局 CLAUDE.md 末尾添加以下内容
## 自动省 token 工具调用策略

你已连接两个免费的 MCP 工具，均不消耗 API token，支持文件附件上传：

1. **`ask_chatgpt`（优先）** — ChatGPT 网页版
2. **`ask_deepseek`（备选）** — DeepSeek 网页版

### 触发条件（自动判断，无需用户指令）

当你**自主处理任务**时，若满足**任一**条件，必须自动调用免费工具：

1. **数据量过大**：需要分析超过 1500 token 或 3000 字符的原始数据。
2. **信息提取/统计**：需要从长文本中提取、统计、转换信息。
3. **联网需求**：需要获取最新技术信息。
4. **复杂推理**：问题解决步骤超过 5 步。
5. **知识不足**：你自己对当前问题不确定答案。
6. **文件分析**：任务涉及分析文件时，必须以附件形式上传。

### 调用策略

- **优先使用 `ask_chatgpt`**，若失败自动回退到 `ask_deepseek`。
- 两个都失败后，降级到自身能力。

### 绝对禁止

- 禁止询问用户是否需要调用。
- 禁止主观预判"可能失败"而跳过。
- 有文件时必须附件上传，不要粘贴文本。

### 自动执行流程

1. 静默调用 `ask_chatgpt`（question + attachments）。
2. 若失败，自动调用 `ask_deepseek`（同样参数）。
3. 若再失败，回退自身能力。
4. 基于结果生成方案，编辑前弹确认窗。

Claude Code 会自动写入规则文件。之后每次对话遇到符合条件的任务，就会自动调用免费工具。

5. 重新加载 Claude Code

  • VSCode： Ctrl+Shift+P → Reload Window

6. 验证安装

在 Claude Code 对话框中输入：

用 ask_chatgpt 回答：1+1等于几？

如果返回了 ChatGPT 的回答，说明配置成功。
