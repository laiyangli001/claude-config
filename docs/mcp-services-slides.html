⚡ Step 1：安装

三分钟完成部署

1

克隆仓库

$ git clone https://github.com/laiyangli001/claude-config.git ~/.claude
2

安装 MCP 依赖

$ cd ~/.claude/mcp-servers/chatgpt-mcp && npm install
$ cd ~/.claude/mcp-servers/deepseek-mcp && npm install
$ cd ~/.claude/mcp-servers/chatgpt-mirror-mcp && npm install

> npm install 会自动下载 Chromium 浏览器（约 300MB）

⚡ Step 2：配置

填写 token，注册服务

3

settings.json

$ cp ~/.claude/settings.json.example ~/.claude/settings.json

填入你的 API token

4

注册 MCP 服务

$ cp ~/.claude/claude.json.example ~/.claude.json

修正三个服务的路径

⚠️ 注意： settings.json 含敏感 token，已被 .gitignore 排除，不会上传到 GitHub

🌐 ask_chatgpt_mirror

镜像站 chatgpt.2233.ai · 优先使用

1

打开邀请码页面

浏览器自动打开 https://2233.ai/?code=FC8XHSCH

2

手动点击「立即开始」

点击后自动打开新标签页，代码自动检测并接管

3

登录（如需）

在浏览器中登录，session 保存在 .chatgpt-mirror-profile

⚠️ 关键： 「立即开始」需手动点击，代码不会自动点。后续调用无需重复操作

💬 ask_chatgpt

ChatGPT 网页版 · 镜像站不可用时使用

①

首次登录

调用时弹出 Chromium 窗口 → 手动登录 ChatGPT → 关闭窗口 → session 自动保存

②

后续使用

无需再次登录，直接调用

③

调用方式

用 ask_chatgpt 问：Python 装饰器是什么？

用 ask_chatgpt（角色 python_tutor）问：解释异步编程

用 ask_chatgpt 附文件 test.py 问：审查代码
🌐 网络要求： 需要能访问 chatgpt.com。镜像站无法使用时才用此服务

🧠 ask_deepseek

DeepSeek 网页版 · 国内直连免 VPN

①

首次登录

调用时弹出 Chromium → 登录 DeepSeek → 关闭窗口 → session 自动保存

②

调用方式

用 ask_deepseek 问：写一个快速排序
③

特点

  • 国内直连，无需 VPN
  • 支持 100MB 文件上传
  • ChatGPT 失败时自动回退

🎭 角色系统

自动检测问题类型，设定 AI 身份

1

自动检测

根据问题关键词匹配角色，首次调用自动发送角色模板给 AI

2

显式指定

python_tutor

✅ python / django / flask / pandas / 装饰器 → 自动触发

❓ 常见问题

遇到问题先看这里

浏览器没弹出？

检查 settings.json 中是否设了 CHATGPT_HEADLESS=false

Failed to launch browser？

运行 npx playwright install chromium 手动安装浏览器

Page crashed？

无法访问 chatgpt.com（试试镜像站），或结束所有 Chrome 进程重试

更新代码后无变化？

VS Code 中 Ctrl+Shift+P → Reload Window
