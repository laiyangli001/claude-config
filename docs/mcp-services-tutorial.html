🛠️ Claude Config 使用教程

三分钟学会安装与使用三个免费的 MCP 服务

📖 这是什么？

一套 Claude Code 的全局配置，包含三个不消耗 API token 的 MCP 服务：

✨ 优先使用

ask_chatgpt

ChatGPT 网页版 · 需能访问 chatgpt.com

自动打开 Chromium 浏览器 → 手动登录 ChatGPT → session 自动保存 → 后续免登录

🌐 国内可用

ask_chatgpt_mirror

镜像站 chatgpt.2233.ai

打开邀请码页面 → 点击「立即开始」→ 弹新标签页 → 登录后自动检测

🔄 备用

ask_deepseek

DeepSeek 网页版 · 国内直连

自动打开 Chromium 浏览器 → 手动登录 DeepSeek → session 自动保存 → 后续免登录

📋 环境要求

Node.js 18+

从 nodejs.org 下载安装，自带 npm

Git

用于克隆仓库和后续更新

磁盘空间 ~1.5GB

主要占用为 Playwright Chromium 浏览器（约 300MB）

网络

DeepSeek 国内直连 · 镜像站需联网 · ChatGPT 可能需要 VPN

⚡ 快速安装

克隆仓库

📂 下载到 ~/.claude
git clone https://github.com/laiyangli001/claude-config.git ~/.claude

安装依赖

进入每个 MCP 服务目录安装 Node.js 依赖：

cd ~/.claude/mcp-servers/chatgpt-mcp && npm install
cd ~/.claude/mcp-servers/deepseek-mcp && npm install
cd ~/.claude/mcp-servers/chatgpt-mirror-mcp && npm install

> npm install 会自动下载 Chromium 浏览器（约 300MB），请保持网络畅通。

配置 settings.json

从模板复制配置文件：

cp ~/.claude/settings.json.example ~/.claude/settings.json

然后编辑 settings.json，将 API token 替换为你的真实 token：

⚠️ 关键： 找到 "ANTHROPIC_AUTH_TOKEN": "sk-<your-api-token-here>"，将占位符替换为实际 token

注册 MCP 服务到 Claude Code

复制全局 MCP 配置文件：

cp ~/.claude/claude.json.example ~/.claude.json

编辑 ~/.claude.json，修正三个服务的路径：

{
  "mcpServers": {
    "chatgpt": {
      "command": "node",
      "args": ["C:/Users/你的用户名/.claude/mcp-servers/chatgpt-mcp/dist/index.js"]
    },
    "deepseek": {
      "command": "node",
      "args": ["C:/Users/你的用户名/.claude/mcp-servers/deepseek-mcp/dist/index.js"]
    },
    "chatgptmirror": {
      "command": "node",
      "args": ["C:/Users/你的用户名/.claude/mcp-servers/chatgpt-mirror-mcp/dist/index.js"]
    }
  }
}

🚀 MCP 服务使用

三者的共同点

首次使用：手动登录一次

调用时自动弹出 Chromium 浏览器 → 在浏览器中登录账号 → 关闭窗口 → session 自动保存

后续使用：免登录

再次调用时直接使用已保存的 session，浏览器自动操作，无需任何手动操作

注意事项

  • 三个服务使用独立的浏览器配置文件，需分别登录一次
  • 如果浏览器没弹出，检查 settings.json 中是否设置了 CHATGPT_HEADLESS=false
  • 每次调用都是"New chat"新对话

ask_chatgpt 详细使用

基础调用

在 Claude Code 中直接说：

用 ask_chatgpt 问：Python 装饰器是什么？

带文件上传

用 ask_chatgpt 附文件 C:\code\test.py 问：审查这段代码

指定角色

用 ask_chatgpt（角色 python_tutor）问：解释异步编程

ask_chatgpt_mirror 详细使用

首次使用流程

  1. 调用后浏览器自动打开 https://2233.ai/?code=FC8XHSCH
  2. 手动点击页面上的「立即开始」按钮
  3. 点击后自动打开新标签页，代码自动检测并切换到新标签页
  4. 如果未登录，在登录页面完成登录
  5. 登录后自动跳转到对话页

注意

  • 「立即开始」需要手动点击，代码不会自动点击
  • 登录 session 保存在 .chatgpt-mirror-profile，后续复用

ask_deepseek 详细使用

基础调用

用 ask_deepseek 问：用 Python 写一个快速排序

特点

  • 国内网络可直接访问，无需 VPN
  • 支持最大 100MB 文件上传，最多 10 个文件
  • 若 ask_chatgpt 失败，自动回退到 ask_deepseek

🎭 角色系统

MCP 服务内置自动角色检测。首次调用时根据问题内容匹配角色模板，设定 AI 身份。

角色触发关键词效果
python_tutorpython, django, flask, 装饰器等Python 编程导师，教学风格回答

显式指定角色：

用 ask_chatgpt（角色 python_tutor）问：解释 async/await

> 只发一个对话标签页只会发送一次角色模板，后续不再重复

❓ 常见问题

浏览器没有弹出窗口 ▼
检查 settings.json 中 CHATGPT_HEADLESS 和 DEEPSEEK_HEADLESS 是否被设为 "true"。设为 "false" 或删除该变量即可。
"Failed to launch browser" 错误 ▼
Playwright Chromium 浏览器没有正确安装。手动运行：
cd ~/.claude/mcp-servers/chatgpt-mcp && npx playwright install chromium
ask_chatgpt 报 "Page crashed" ▼
常见原因：1) 无法访问 chatgpt.com（尝试用 ask_chatgpt_mirror）；2) 浏览器配置目录被锁定（结束所有 Chrome 进程后重试）
镜像站检测不到新标签页 ▼
确保在浏览器中手动点击了「立即开始」按钮。代码依赖该按钮打开的新标签页，不会自动点击。
更新代码后还是旧行为 ▼
VS Code 中按 Ctrl+Shift+P → Reload Window 重启，让 MCP 服务器重新加载。
