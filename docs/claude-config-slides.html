生成 au3 的提示词模板

我需要一个 AutoIt3 脚本，实现以下需求：
<描述需求，例如：每 10 秒检测窗口是否存在>

请生成：
- 完整的 .au3 脚本代码
- 编译命令（使用 @Aut2Exe/Aut2exe_x64.exe，/console 参数）
- 从 Node.js/Python 调用该 exe 的示例代码

编译命令（无窗口静默）

cmd //c "@Aut2Exe/Aut2exe_x64.exe /in "C:\path\to\script.au3" /out "C:\path\to\output.exe" /console"
# 或用绝对路径：
cmd //c "@C:\Users\<用户名>\.claude\Aut2Exe\Aut2exe_x64.exe /in "C:\full\path\to\script.au3" /out "C:\full\path\to\output.exe" /console"
⚠️ 必须使用 /console 参数，否则会弹出窗口
编译时杀毒软件可能拦截，需添加信任区（白名单）

🔗 MCP + 死循环 联合使用

全自动脱困-求助-修复闭环（自动执行，不需要手动）

1

监控阶段

死循环监控持续扫描 .jsonl 日志

2

检测到死循环 → ESC 中断

deadloop_control.exe esc 长按 ESC 5 秒打断输出，确认停止（扫描 stop_reason: "end_turn"）

3

注入求助指令

inject_file 将摘要生成指令粘贴到 Claude Code 输入框并自动提交 → Claude Code 自动调用 ask_chatgpt

4

获取答案 → 修复代码

ChatGPT 返回审查结果/修复建议 → Claude Code 按内容修改代码

5

冷却恢复

10 秒冷却后继续监控

配置要点： permissions.allow 包含 mcp__chatgpt__ask_chatgpt 和 mcp__deepseek__ask_deepseek · 阈值在 config.mjs 调整 · 无人值守设 CHATGPT_HEADLESS=true

❓ 常见问题

遇到问题先看这里

浏览器没有弹出窗口？

检查 settings.json 中 CHATGPT_HEADLESS 是否被设为 "true"。设为 "false" 或删除该变量即可。

"Failed to launch browser" 错误？

Playwright Chromium 没有正确安装。手动运行：cd chatgpt-mcp && npx playwright install chromium

ask_chatgpt 报 "Page crashed"？

1) 无法访问目标站点（尝试切换 target 参数）
2) 浏览器配置目录被锁定（结束所有 Chrome 进程后重试）

更新代码后还是旧行为？

VS Code 中 Ctrl+Shift+P → Reload Window 重启，让 MCP 服务重新加载。

如何调整死循环检测灵敏度？

编辑 deadloop-monitor/config.mjs，调整重复次数、反转词密度、信息增量率等阈值参数。
